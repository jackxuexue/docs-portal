# HTTP ERROR CODES

- **Code**: Description
- **0**: success
- **200**: success
- **4xx**: client issue
- **5xx**: server issue
- **999999**: unknown error
- **602001**: repeat commit
- **602002**: device not exist
- **602003**: not support
- **602004**: device offline
- **602005**: gateway not exist
- **602006**: no authority of this station
- **603001**: work mode command send error
