# Glossary

- **Term**: Description
- **appId**: Third-party APP Unique ID
- **appSecret**: Third-party APP Secret
- **token**: A short-lived credential used to access protected resources (APIs/data) on behalf of an authenticated user or client.
- **refresh_token**: A long-lived credential used to obtain a new access_token without requiring user re-authentication.
