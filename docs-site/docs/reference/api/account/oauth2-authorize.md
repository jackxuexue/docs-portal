## OAuth2 Authorize

- **Description**: return Sofar cloud ouath2.0 authorize page
- **Url**: /oauth/v2/authorize
- **Method**: GET
- **Content-Type**: application/json

## Request Parameters

| Parameter | Data Type | Type | Require | Description |
|---|---|---|---|---|
| appId | String | Query | Y | appId（contact with SOLFAR CLOUD） |
| responseType | String | Query | Y | the type of authorization response desired. Use code for Authorization Code flow.<br>fixed value: code |
| redirectUri | String | Query | Y | redirect Uri |
| scope | String | Query | N | spacedelimited list of permission scopes that the client requests. If omitted, server applies clientconfigured default scopes. |
| state | String | Query | N | recommended for security. Opaque random string generated by client. The authorization server returns this unchanged in callback URI. Used to mitigate CSRF attacks by validating request consistency between authorization initiation and callback. |

## Example

### Request

```json
https://eu.sofarcloud.com/api/openapi/oauth/v2/authorize?responseType=code&appId=demo_client_001&redirectUri=https%3A%2F%2Fclient-demo.com%2Fcallback&scope=user_info%20phone&state=9a7b2f41d8ce44ab91e32bc7d3456789
```

### Response

```json
redirect to Sofar cloud Oauth2.0 authorize page.
```
