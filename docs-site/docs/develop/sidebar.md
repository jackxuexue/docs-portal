# Sidebar management

Site navigation lives in `docs/.vitepress/config.mts` as the `sidebar`
option. The workbench owns exactly one small region of that file — the
**managed block** — and never touches anything else.

## The managed block

```mts
const sidebar = {
  // ---sidebar:auto-begin---
  { ...JSON managed by the workbench... }
  // ---sidebar:auto-end---
}
```

Everything **outside** the markers stays hand-editable: branding, search
config, edit links, plugins. Everything **between** the markers is plain JSON
generated by the workbench — treat it as an output, not an input.

## Editing in the workbench

- Drag pages within a group to reorder; drag a page onto another group to move it
- Drag whole groups to reorder sections
- Add, rename, and remove groups; toggle a group's *collapsed* default
- **Save** rewrites only the JSON between the markers

## Sidebar ↔ pages

- **New page**: created via the workbench is appended to the group matching its
  directory, so a page in `guide/` lands under the *Guide* group
- **Rename**: links inside the sidebar JSON are rewritten to the new path
- **Delete**: sidebar entries pointing at the page are removed; groups left
  empty disappear

If you restructure by hand in a file manager, open the workbench afterwards —
the tree view reflects whatever is on disk, and stale sidebar links are what
to check first.
