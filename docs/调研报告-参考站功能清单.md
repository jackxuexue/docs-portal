## 2. 站点功能(页面三栏布局)

### 2.1 顶栏(NavBar)
- **主导航 3 项**:Guide / Development / Reference,每项带 `activeMatch` 正则(如 `^/guide/`)实现当前区高亮
- **语言切换**(VPFlyout 菜单):简体中文 ↔ English,互链对应语言的同一页
- **深浅色切换**(VPSwitch,localStorage `vitepress-theme-appearance`,支持 auto 跟随系统)
- **GitHub 社交链接**:`https://github.com/deepseek-ai/deepseek-harness`
- **自定义品牌 siteTitle**:SVG wordmark(非文字)+ 徽标胶囊("技术预览"/"Preview")
- 移动端:VPNavBarHamburger + VPLocalNav(带"返回顶部"outline 下拉)
- 自定义 CSS:侧边栏细滚动条(hover 才显示 thumb)

### 2.2 左侧 Sidebar(带分组的文档树)
- 按路径段路由:`/guide/`、`/develop/`、`/reference/` 三大区各自一套 sidebar
- 分组 = 组标题(h2)+ 页面链接;长分组带 `collapsed: true` 默认折叠
- 跨区快捷链接(如 guide 区 sidebar 末尾直接放 Development / Reference 入口)
- `/reference/` 区含 **47 个子系统页面** 组成的 7 个折叠分组

### 2.3 右侧 Outline
- "On this page"(中文"本页目录"),滚动跟随 + 高亮指示条

### 2.4 页脚(DocFooter)
- **上一篇/下一篇** pager(文案本地化:上一篇/下一篇)
- **editLink**:"在 GitHub 上编辑此页" → 指向 `github.com/deepseek-ai/deepseek-harness/edit/master/<editSource>`

### 2.5 本地全文搜索
- `themeConfig.search.provider: "local"`(客户端 minisearch 索引,无外部服务)
- 中文界面文案齐全(搜索文档/未找到相关结果/Esc 键 等)

### 2.6 Markdown 渲染增强
- 代码高亮(VitePress 内置 Shiki,`vp-code` 类)、表格
- **KaTeX** 数学公式(chunk 预加载)
- **Mermaid** 全图表类型 chunk 预加载:flowchart/sequence/class/state/ER/gantt/pie/mindmap/timeline/kanban/sankey/xychart/c4/gitGraph 等 30+ 种 → 接入了 `vitepress-plugin-mermaid` 全量注册
- 标题 header anchors(悬停锚点链接)

## 3. 双语 i18n 体系

| 项 | 内容 |
|---|---|
| locales | `root`(简体中文,zh-CN,默认)+ `en`(English,en-US,`/en/` 路径) |
| 隔离度 | 每语言独立 nav / sidebar / 全套 UI 文案(langMenuLabel、docFooter、darkModeSwitchLabel 等) |
| 页面对称 | 两种语言页面一一对应(~89 页/语言) |

**内容源三件套**(仓库 `docs/` 目录,每种文档三个文件):
- `<name>.md` — 英文源(主文件)
- `<name>.zh.md` — 中文翻译
- `<name>.i18n.yaml` — i18n 元数据(约 420–500 字节,标题/摘要/状态类信息)

翻译配套体系(`docs/i18n/`):`terminology.md` 术语表、`translation-rules.md` 翻译规则、`translation-prompt.md`(23KB 的 LLM 翻译提示词)、`style-samples.md` 风格样例 —— 一套系统化的 AI 辅助翻译工作流。

## 4. 内容管线(对"文档管理"最有参考价值的部分)

1. **单一事实源**:仓库 `docs/` 目录是全部文档源;站点只是它的一个投影视图
2. **投影(projector)机制**:对外站点内容来自 `docs/user/`(guide/develop/reference 三大板块),投影页带 `editSource` frontmatter(如 `docs/user/guide/index.md`),editLink 的 pattern 函数读取该 frontmatter 拼出 GitHub 编辑链接;缺 editSource 会报错 "Projected documentation page has no editSource frontmatter"
3. **生成类参考文档**:config-catalog(146KB)、tool-catalog(92KB)、persistence-catalog(37KB)、module-graph(114KB)等由脚本从代码生成,再入管
4. **文档规范**:`docs/AGENTS.md`(10KB)定义文档写作/命名/结构规范
5. **规模**:docs 目录 373 个条目,站点约 89 页/语言 × 2

**站点信息架构**(sidebar 全结构,中文为准):
- `/guide/`:入门(使用 Web UI、配置模型)、SDK(Python)、自动化(GitHub 评审会话、会话内提醒)、集成(记忆 MCP)
- `/develop/`:基础(第一个插件、Tool、配置、打包)、框架能力(生命周期、服务、事件)、实战(三层拆分、LLM 适配器、运行时 Cordis)、Cordis 教程(7 章)
- `/reference/`:概念(架构、Cordis 入门、能力 seam、Agent 生命周期、Tool 执行、API Gateway)、生成参考(配置/Tool Schema/持久化事件)、Cordis API(6 篇)、开发手册(5 篇)、子系统(47 篇,7 折叠组)

## 5. 本站(开发目标)的取舍结论

| 参考站能力 | 本站决策 |
|---|---|
| VitePress + 静态托管 + cleanUrls | ✅ 照做 |
| 三栏布局、分组侧边栏、outline、pager | ✅ VitePress 默认能力 |
| 本地全文搜索 | ✅ 照做(英文) |
| 深浅色切换 | ✅ 默认 |
| Mermaid + KaTeX | ✅ 接入插件 |
| editLink 回链源文件 | ✅ 简化版(直接指仓库路径) |
| 双语 i18n + 翻译管线 | ❌ 用户决策:仅英文 |
| 投影/生成文档管线 | ❌ 本期不做(后续增强) |
| 后台管理界面(参考站无) | ➕ 用户需求:自研文档管理台 |
